The course

Eight sessions

The materials are split into eight sessions, which do not map one-to-one onto the five timetabled sessions for the Summer School workshop. Normally we teach this course in 8 weekly sessions. For this workshop will work through the materials in order and hopefully at least cover the first 7 sessions. The materials will remain available after the workshop, so you can work through the later sessions in your own time.

Each session carries its own exercises with the answers folded away until you want them. You can work through these exercises in your own time.

  • Session 1Data types and structuresAn introduction to RStudio, R objects, data types, functions and vectors
  • Session 2Other data structuresMatrices, lists and data frames, and how to get around them
  • Session 3Working with data in RReading, inspecting and writing tabular data
  • Session 4Visualizing data with ggplot2A common grammar for scatter plots, bar charts, boxplots, histograms and time series
  • Session 5Data manipulation with dplyrFiltering and modifying tabular data, computing summary values, faceting with ggplot2
  • Session 6Grouping and combining dataAdvanced grouping and summarization, joining tables, customizing ggplot2 plots
  • Session 7Restructuring data for analysisThe concept of ‘tidy data’, pivoting and separating operations, ggplot2 extras
  • Session 8QuartoCreating reproducible reports that combine code, output and prose
About this course

Why learn R?

R is one of the leading programming languages in data science, and the most widely used within the CRUK Cambridge Institute for interacting with, analyzing and visualizing cancer biology data sets.

In this training course we aim to provide a friendly introduction to R, pitched at a beginners level. We focus on manipulating tabular data and visualising data, using a suite of packages known as the tidyverse — in particular the dplyr and ggplot2 packages.

Working in scripts makes the steps of an analysis explicit: they can be inspected by someone else, checked for errors, and re-run. An increasing number of journals and funding agencies expect analyses to be reproducible, so knowing R puts you ahead.

Before the first session

Set your laptop up first

You will need R and the tidyverse installed, and the workshop data downloaded, before the first session. Installing R and its packages is usually straightforward, but it can go wrong in ways that take time to fix — so please work through the setup in advance and bring a laptop that already works.

The data set is a single zip file. Download it, unzip it, and keep the Bioinformatics_Workshop folder somewhere you can find again — every session reads its files from the data directory inside it.

If you get stuck, bring the error message with you and we will sort it out before the practical starts.
