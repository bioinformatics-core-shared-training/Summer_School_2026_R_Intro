dplyr verbs

  • dplyr functions are “verbs” in a grammar of data manipulation – all share the same syntax:

  • The first argument in each function is a data frame (or tibble)

  • Any additional arguments describe what operation to perform on the data frame

  • Variable names, i.e. column names, are referred to without using quotes

  • The result of an operation is a new data frame

patients <- filter(metabric,
                   Survival_status == "LIVING" & Survival_time > 120)
patient_details <- select(patients,

                          Tumour_stage,
                          Nottingham_prognostic_index)

patients <- select(patients,

x <- c(24, 53, 352, 643, 46)

patients <- select(filter(metabric, Survival_status == "LIVING", Survival_time > 120), Patient_ID, Survival_time)

The pipe operator |>

  • Takes the left-hand side and passes it as the first argument to the function on the right

x |> f(y) is equivalent to f(x, y)

For example:

select(starwars, name, height, mass)

can be rewritten as

starwars |> select(name, height, mass)

Chained into a workflow:

starwars |>
    filter(species == "Droid") |>
    select(name, height, mass)

  • Built into R – no package needed; modelled on the Unix pipe |
  • Called the native pipe; needs R 4.1+
  • You will meet %>% (magrittr, loaded with tidyverse) in older code – read it as |>; we use |> throughout
patients <- metabric |>
    filter(Survival_status == "LIVING" & Survival_time > 120) |>
    select(Patient_ID, Survival_time, Tumour_stage, Nottingham_prognostic_index)
  • Why tidyverse functions always take the data frame first and always return a data frame – so they pipe
  • Build a workflow one step at a time, checking the output as you go
patients <- metabric |>
    filter(Survival_status == "LIVING")
patients <- metabric |>
    filter(Survival_status == "LIVING") |>
    filter(Survival_time > 120)
patients <- metabric |>
    filter(Survival_status == "LIVING") |>
    filter(Survival_time > 120) |>
    select(Patient_ID, Survival_time, Tumour_stage, Nottingham_prognostic_index)
# print out the result
patients
## # A tibble: 545 × 4
##   Patient_ID Survival_time Tumour_stage Nottingham_prognostic_index
##   <chr>              <dbl>        <dbl>                       <dbl>
## 1 MB-0000             140.            2                        6.04
## 2 MB-0006             165.            2                        4.05
## # ℹ 543 more rows
  • Gotcha: |> must be at the end of the line, not the start of the next
# R considers the following to be 2 separate commands, the first of which ends
# with the first filter operation and runs successfully.
# The second statement is the third and last line, is not a valid command and
# so you'll get an error message
patients <- metabric |>
    filter(Survival_status == "LIVING")
    |> filter(Survival_time > 120)
  • Same rule as + in ggplot2

Modifying data using mutate()

  • Base R way – add a new logical column with $
metabric$Deceased <- metabric$Survival_status == "DECEASED"
  • dplyr way – mutate(); new column added at the end; no metabric$ prefix needed
metabric <- mutate(metabric, Deceased = Survival_status == "DECEASED")
  • mutate() can overwrite an existing column – common for unit conversion
  • Tumour size is in mm, NPI formula needs cm
metabric <- mutate(metabric, Tumour_size = Tumour_size / 10)

Nottingham Prognostic Index

Prognosis after breast cancer surgery, from three pathological criteria.

NPI = (0.2 * S) + N + G

  • S is the size of the tumour in centimetres
  • N is the node status (0 nodes = 1, 1-3 nodes = 2, >3 nodes = 3)
  • G is the grade of tumour (Grade I = 1, Grade II = 2, Grade III = 3)
  • Recalculate NPI and compare with the column already in the data
metabric <- metabric |>
    mutate(NPI = (0.2 * Tumour_size) +
               Lymph_node_status +
               Neoplasm_histologic_grade)

select(metabric,
       Tumour_size,
       Lymph_node_status,
       Neoplasm_histologic_grade,
       NPI,
       Nottingham_prognostic_index)

read_csv("data/metabric_clinical_and_expression_data.csv") |>
    mutate(Tumour_size = Tumour_size / 10) |>
    mutate(NPI = (0.2 * Tumour_size) +

    select(Tumour_size, Lymph_node_status, Neoplasm_histologic_grade, NPI)

Mutating multiple columns

  • Two identical rounding steps above – collapse into one with across()
  • across() goes inside mutate(): first argument = columns, second = function to apply
metabric |>
    mutate(across(c(Tumour_size, NPI), round)) |>
    select(Patient_ID, Tumour_size, NPI)
## # A tibble: 1,904 × 3
##   Patient_ID Tumour_size   NPI
##   <chr>            <dbl> <dbl>
## 1 MB-0000              2     6
## 2 MB-0002              1     4
## # ℹ 1,902 more rows
  • Harder case: no ready-made function, or you need to pass extra arguments
  • Use an anonymous function – no name, exists only inside the mutate() call
  • Example: cm to mm in iris; there is no “multiply by 10” function
iris |>
    as_tibble() |>
    mutate(across(Sepal.Length:Petal.Width, ~ .x * 10))

## 2           49          30           14           2 setosa 
## # ℹ 148 more rows

  • To pass extra arguments to an existing function: ~func(.x, ...)
metabric |>
    mutate(across(c(Tumour_size, NPI), ~round(.x, digits = 1))) |>
    select(Patient_ID, Tumour_size, NPI)

Computing summary values using summarise()

  • Brief here – comes into its own with group_by() next session
  • Any function collapsing a vector to a single value works
mean(metabric$ESR1)
## [1] 9.607824
summarise(metabric, mean(ESR1))
## # A tibble: 1 × 1
##   `mean(ESR1)`
##          <dbl>
## 1         9.61
  • summarize() spelling also works
  • Key difference: mean() returns a length-1 vector, summarise() returns a data frame (1 row, 1 column)
  • Useful when summarising several columns or using several functions – and you can name the output columns
summarise(metabric, ESR1_mean = mean(ESR1), ESR1_sd = sd(ESR1))
## # A tibble: 1 × 2
##   ESR1_mean ESR1_sd
##       <dbl>   <dbl>
## 1      9.61    2.13

summarise()

summarise() collapses a data frame into a single row by calculating summary values of one or more of the columns.

Takes any function that maps a vector to a single value:

  • Centre: mean(), median()
  • Spread: sd(), mad()
  • Range: min(), max(), quantile()
  • Position: first(), last()
  • Count: n()

first(), last() and n() are only really useful with group_by().

n() is special – returns the number of observations, takes no column argument.

  • Summary functions can span two columns, e.g. a correlation
summarise(metabric, correlation = cor(FOXA1, MLPH))
## # A tibble: 1 × 1
##   correlation
##         <dbl>
## 1       0.898

Summarizing multiple columns

  • across() works here too
summarise(metabric, across(c(FOXA1, MLPH), mean))
## # A tibble: 1 × 2
##   FOXA1  MLPH
##   <dbl> <dbl>
## 1  10.8  11.4
  • everything() selects all columns
metabric |>
    select(ESR1:MLPH) |>
    summarise(across(everything(), mean))
## # A tibble: 1 × 8
##    ESR1 ERBB2   PGR  TP53 PIK3CA GATA3 FOXA1  MLPH
##   <dbl> <dbl> <dbl> <dbl>  <dbl> <dbl> <dbl> <dbl>
## 1  9.61  10.8  6.24  6.20   5.97  9.50  10.8  11.4

metabric |>
    summarise(across(c(ESR1, ERBB2, PGR), list(mean, sd)))

metabric |>
    summarise(across(c(ESR1, ERBB2, PGR), list(Average = mean, stdev = sd)))

##   ESR1_Average ESR1_stdev ERBB2_Average ERBB2_stdev PGR_Average PGR_stdev

## 1         9.61       2.13          10.8        1.36        6.24      1.02
  • Anonymous functions work in summarise() too – correlate every gene against FOXA1
  • Note the -FOXA1 to exclude it from the selection (correlation with itself = 1)
metabric |>
    summarise(across(c(ESR1:MLPH, -FOXA1), ~cor(.x, FOXA1)))

Faceting with ggplot2

  • Faceting splits a plot into subplots, each showing a subset of the data, by one or more categorical variables
  • Two functions: facet_wrap() and facet_grid()
  • Start with the colour-aesthetic version from last session
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = PR_status)) +
    geom_point(size = 0.5, alpha = 0.5)
  • Same data, faceted instead – one panel per category with a banner label
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(PR_status))
  • Faceting variables go inside vars() – unquoted column names, as in select() and across()
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = PR_status)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(PR_status))
  • Faceting beats colours once there are more than two or three groups – e.g. the 3-gene classifier
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = `3-gene_classifier`)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(`3-gene_classifier`))
  • Hence the name – panels wrap onto a new row; control with nrow / ncol
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = `3-gene_classifier`)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(`3-gene_classifier`), nrow = 1)
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = `3-gene_classifier`)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(`3-gene_classifier`), ncol = 2)
  • Facet on one variable, colour by another
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = HER2_status)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(Neoplasm_histologic_grade))
  • Or facet on two variables – facet_wrap() gives a flat ribbon of every combination
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_wrap(vars(Neoplasm_histologic_grade, HER2_status))
  • Two variables are better as a grid – facet_grid(), rows then columns
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_grid(vars(Neoplasm_histologic_grade), vars(HER2_status))
  • Naming rows = and cols = explicitly is clearer
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1, colour = PAM50)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_grid(rows = vars(Neoplasm_histologic_grade),
               cols = vars(HER2_status))
  • labeller – replace raw category values with meaningful panel labels
grade_labels <- c("1" = "Grade I", "2" = "Grade II", "3" = "Grade III")
her2_status_labels <- c("Positive" = "HER2 positive",
                        "Negative" = "HER2 negative")

ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1, colour = PAM50)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_grid(rows = vars(Neoplasm_histologic_grade),
               cols = vars(HER2_status),
               labeller = labeller(Neoplasm_histologic_grade = grade_labels,
                                   HER2_status = her2_status_labels))
  • Essential once two variables share one side of the grid – “Positive”/“Positive” tells you nothing
er_status_labels <- c("Positive" = "ER positive", "Negative" = "ER negative")
#
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1, colour = PAM50)) +
    geom_point(size = 0.5, alpha = 0.5) +
    facet_grid(rows = vars(Neoplasm_histologic_grade),
               cols = vars(ER_status, HER2_status),
               labeller = labeller(Neoplasm_histologic_grade = grade_labels,
                                   ER_status = er_status_labels,
                                   HER2_status = her2_status_labels))
