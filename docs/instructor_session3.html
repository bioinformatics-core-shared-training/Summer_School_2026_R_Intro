read_csv() and read_tsv()

  • read_csv() – comma-separated files; read_tsv() – tab-delimited
  • Both expect column names on line 1 and guess column types
  • Arguments let you skip comment lines (e.g. “#”) or set column types explicitly
  • Point out the back ticks around column names – spaces, dashes, one starting with a number
  • R only allows “_” and “.” in names, and no leading number
  • clean_names() from janitor fixes them all at once

Data semantics

  • Observations are rows, variables are columns – say it explicitly

From “Tidy Data” by Hadley Wickham, The Journal of Statistical Software, vol. 59, 2014.

  • A data set is a collection of values; every value belongs to a variable and an observation
  • A variable – all values measuring the same attribute across units
  • An observation – all values measured on the same unit across attributes

dplyr verbs

  • filter() for filtering rows

  • select() for selecting columns

  • arrange() for sorting rows

  • mutate() for modifying columns or creating new ones

  • summarise() for computing summary values

  • group_by() combines with these to work per group – covered later

  • Called “verbs” in a grammar of data manipulation; shared syntax:

    • First argument is a data frame (or tibble)
    • Further arguments describe the operation
    • Column names unquoted
    • Result is a new data frame

Filtering rows with filter()

  • Picks rows matching criteria built from comparison operators ==, >, <, !=

## 2 MB-0008         1             77.0          41.4 DECEASED        Died of Dise…

  • == tests equality – not assignment
  • Equivalent to base R subsetting with a logical vector
filter(metabric, Vital_status == "Died of Disease")
# is equivalent to
metabric[metabric$Vital_status == "Died of Disease", ]
  • dplyr version: metabric written once, column name unquoted
table(metabric$Vital_status)
## 
##      Died of Disease Died of Other Causes               Living 
##                  622                  480                  801
  • != – everything that isn’t “Living”
deceased <- filter(metabric, Vital_status != "Living")
nrow(deceased)
## [1] 1102
  • %in% – test membership of a set of values
deceased <- filter(metabric,
                   Vital_status %in% c("Died of Disease", "Died of Other Causes"))
nrow(deceased)
## [1] 1102
  • stringr (tidyverse) for text; str_starts() matches the start of a string
deceased <- filter(metabric, str_starts(Vital_status, "Died"))
nrow(deceased)
## [1] 1102
  • str_starts() returns a logical vector – the filter condition must be TRUE/FALSE per row
  • Also str_ends(), and str_detect() for regular expressions (out of scope)
  • Next: filtering on a logical variable – we have none, so create one
# create a new logical variable called 'Deceased'
metabric$Deceased <- metabric$Survival_status == "DECEASED"
#
# filtering based on a logical variable - only selects TRUE values
deceased <- filter(metabric, Deceased)
#
# only display those columns we're interested in
deceased[, c("Patient_ID", "Survival_status", "Vital_status", "Deceased")]

## 2 MB-0008    DECEASED        Died of Disease TRUE    
## # ℹ 1,101 more rows
  • ! negates
filter(metabric, !Deceased)
  • Row count differs by one from the Vital_status filters – one patient has a missing vital status
  • is.na() is the only way to test for NA
missing_vital_status <- filter(metabric, is.na(Vital_status))

                         "Vital_status",

## 1 MB-5130    DECEASED        <NA>         TRUE
  • Key gotcha: filter() keeps only TRUE – both FALSE and NA are dropped
  • Multiple conditions, comma separated
filter(metabric, Survival_status == "LIVING", Survival_time > 120)
## # A tibble: 545 × 33
##   Patient_ID Cohort Age_at_diagnosis Survival_time Survival_status Vital_status
##   <chr>       <dbl>            <dbl>         <dbl> <chr>           <chr>       
## 1 MB-0000         1             75.6          140. LIVING          Living      
## 2 MB-0006         1             47.7          165. LIVING          Living      
## # ℹ 543 more rows
## # ℹ 27 more variables: Chemotherapy <chr>, …
metabric[metabric$Survival_status == "LIVING" & metabric$Survival_time > 120, ]
  • Base R gets steadily more unreadable with each extra condition
  • Comma is equivalent to & (Boolean AND)
filter(metabric, Survival_status == "LIVING", Survival_time > 120)
  • | (Boolean OR) for either/or; combine both for complex criteria
selected_patients <- filter(metabric,
                            Tumour_stage >= 3,
                            ER_status == "Positive" | PR_status == "Positive")
nrow(selected_patients)
## [1] 79
  • Swap comma for & and you must mind operator precedence – use parentheses
filter(metabric, Tumour_stage >= 3 &
           (ER_status == "Positive" | PR_status == "Positive"))
