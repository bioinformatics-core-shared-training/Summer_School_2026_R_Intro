# Progress (F37)

The CRUK Cambridge Institute's display face, used for headings and the site
brand. Copied from the Summer School site's `assets/fonts/` so the two sites
share typography.

Progress is a **licensed** brand face, not freely redistributable. Only the
four web formats needed to render the site are published here — the `.otf` /
`.ttf` desktop masters must stay out of the repository, as they do in the
Summer School repo.

The display stack in `assets/css/site.css` falls back to Poppins (Google
Fonts, SIL Open Font Licence), so headings degrade gracefully if these files
are unavailable or blocked.
