Grouping observations

Summaries for groups

  • Recap: summarise() over all rows
summarise(metabric, mean(ESR1))
## # A tibble: 1 × 1
##   `mean(ESR1)`
##          <dbl>
## 1         9.61
  • Real power is per-group – the alternative is filtering each category by hand
  • Two ways: group_by() or the .by argument
metabric |>
    group_by(ER_status) |>
    summarise(mean(ESR1))
## # A tibble: 2 × 2
##   ER_status `mean(ESR1)`
##   <chr>            <dbl>
## 1 Negative          6.21
## 2 Positive         10.6

or

metabric |>
    summarise(mean(ESR1), .by = ER_status)
## # A tibble: 2 × 2
##   ER_status `mean(ESR1)`
##   <chr>            <dbl>
## 1 Positive         10.6 
## 2 Negative          6.21

Show the group and summarise diagram here

  • Extra column for the grouping variable, one row per category
  • With a single grouping column the two methods are identical
  • Sanity check – ER+ should be higher; values are log2, so the difference is a fold change
2 ^ (10.6 - 6.21)  # equivalent to (2 ^ 10.6) / (2 ^ 6.21)
## [1] 20.96629

metabric |>

  • Always show n alongside a summary – tells you if a mean rests on 3 samples

Missing values

  • Most summary functions return NA if any value is NA – NA propagation
metabric |>
    summarize(N = n(),
              `Average tumour size` = mean(Tumour_size),
              .by = ER_status)
## # A tibble: 2 × 3
##   ER_status     N `Average tumour size`
##   <chr>     <int>                 <dbl>
## 1 Positive   1459                    NA
## 2 Negative    445                    NA
  • na.rm = TRUE excludes them
metabric |>
    summarize(N = n(),
              `Average tumour size` = mean(Tumour_size, na.rm = TRUE),
              .by = ER_status)
## # A tibble: 2 × 3
##   ER_status     N `Average tumour size`
##   <chr>     <int>                 <dbl>
## 1 Positive   1459                  25.6
## 2 Negative    445                  28.5
  • Filtering instead changes what N means – may or may not be what you want
metabric |>
    filter(!is.na(Tumour_size)) |>
    summarize(N = n(),
              `Average tumour size` = mean(Tumour_size),
              .by = ER_status)
## # A tibble: 2 × 3
##   ER_status     N `Average tumour size`
##   <chr>     <int>                 <dbl>
## 1 Positive   1446                  25.6
## 2 Negative    438                  28.5

Counts and proportions

  • sum() and mean() on logical vectors – count of TRUE, proportion TRUE
metabric |>
    summarize(N = n(),
              Missing = sum(is.na(Tumour_size)),
              `Average tumour size` = mean(Tumour_size, na.rm = TRUE),
              .by = ER_status)
## # A tibble: 2 × 4
##   ER_status     N Missing `Average tumour size`
##   <chr>     <int>   <int>                 <dbl>
## 1 Positive   1459      13                  25.6
## 2 Negative    445       7                  28.5
  • Why it works: is.na() returns a logical vector
test_vector <- c(1, 3, 2, NA, 6, 5, NA, 10)
is.na(test_vector)
## [1] FALSE FALSE FALSE  TRUE FALSE FALSE  TRUE FALSE
  • Coercion – FALSE is 0, TRUE is 1, so sum() counts
sum(is.na(test_vector))
## [1] 2
mean(is.na(test_vector))
## [1] 0.25
metabric |>
    summarize(N = n(),
              `Missing tumour size` = sum(is.na(Tumour_size)),
              `Proportion missing` = mean(is.na(Tumour_size)),
              .by = ER_status)
## # A tibble: 2 × 4
##   ER_status     N `Missing tumour size` `Proportion missing`
##   <chr>     <int>                 <int>                <dbl>
## 1 Positive   1459                    13              0.00891
## 2 Negative    445                     7              0.0157
  • Works for any condition returning a logical vector, not just is.na()
metabric |>
    filter(Survival_status == "DECEASED") |>
    summarise(N = n(),
              N_long_survival = sum(Survival_time > 120),
              Proportion_long_survival = mean(Survival_time > 120),
              .by = ER_status)
## # A tibble: 2 × 4
##   ER_status     N N_long_survival Proportion_long_survival

Joining data

  • Data usually spread across tables from different sources
  • dplyr joins combine two tables on matching values in a shared column – same idea as SQL joins

left_join

Show the left join diagram here

  • left_join() keeps all rows of the left table; unmatched rows get NA in the new columns
  • Toy example: Ugandan park animals and what they eat
  • RDS – R’s own format for one saved object; read with read_rds()
animals <- read_rds("data/animals.rds")
animal_diets <- read_rds("data/animal_diets.rds")
  • by takes the matching column name as a string
animals
## # A tibble: 3 × 2
##   animal   park           
##   <chr>    <chr>          
## 1 lion     Kidepo Valley  
## 2 elephant Murchison Falls
## # ℹ 1 more row
animal_diets
## # A tibble: 3 × 2
##   animal    eats  
##   <chr>     <chr> 
## 1 elephant  plants
## 2 crocodile meat  
## # ℹ 1 more row
left_join(animals, animal_diets, by = "animal")
## # A tibble: 3 × 3
##   animal   park            eats  
##   <chr>    <chr>           <chr> 
## 1 lion     Kidepo Valley   <NA>  
## 2 elephant Murchison Falls plants
## # ℹ 1 more row
  • Lion: in left only -> kept, eats is NA
  • Hippo: in right only -> dropped
  • NA means “not recorded here”, not “lions don’t eat”
  • right_join() – all rows of the right table; rarely used
right_join(animals, animal_diets, by = "animal")
## # A tibble: 3 × 3
##   animal    park            eats  
##   <chr>     <chr>           <chr> 
## 1 elephant  Murchison Falls plants
## 2 crocodile Murchison Falls meat  
## # ℹ 1 more row

Customizing plots with ggplot2

Titles and labels

  • labs() – name-value pairs; any aesthetic plus title, subtitle, caption
ggplot(metabric, mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +
    geom_smooth(method = "lm") +
    labs(title = "mRNA expression in the METABRIC breast cancer data set",
         subtitle = "Expression measured with Illumina bead arrays",
         x = "log2 GATA3 expression",
         y = "log2 ESR1 expression",
         colour = "ER status")
## `geom_smooth()` using formula = 'y ~ x'
  • Labels are another element of the plot object, alongside mappings and layers
  • Naming the colour aesthetic is what tidies the legend title

Scales

  • ggplot2 picks scales from the data type: continuous for GATA3/ESR1, discrete for ER_status
  • Add scale layers to override; naming convention:
scale_<NAME_OF_AESTHETIC>_<NAME_OF_SCALE>
  • Show the scale_y_continuous help page
  • breaks – where ticks and labels go
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +
    geom_smooth(method = "lm") +
    scale_y_continuous(breaks = seq(5, 15, by = 2.5))
## `geom_smooth()` using formula = 'y ~ x'
  • seq() – regular sequences, from/to/by
seq(5, 15, by = 2.5)
## [1]  5.0  7.5 10.0 12.5 15.0
  • limits – axis extents; deliberately clipped here, expect the “removed rows” warning
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +
    geom_smooth(method = "lm") +
    scale_y_continuous(breaks = seq(5, 15, by = 2.5), limits = c(4, 12))

  • theme() controls the non-data components
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +

ggplot(data = metabric,

Colours

  • Default for a categorical variable is scale_colour_discrete; override with scale_colour_manual
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +
    geom_smooth(method = "lm") +
    scale_colour_manual(values = c("dodgerblue2", "firebrick2"))
## `geom_smooth()` using formula = 'y ~ x'
  • Name the values to control which colour goes with which category
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +
    geom_smooth(method = "lm") +
    scale_colour_manual(values = c(Positive = "dodgerblue2",
                                   Negative = "firebrick2"))
## `geom_smooth()` using formula = 'y ~ x'
  • Manual is fine for two or three categories; beyond that use a palette
  • ColorBrewer palettes via scale_colour_brewer() / scale_fill_brewer()
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = `3-gene_classifier`)) +
    geom_point(size = 0.6, alpha = 0.5, na.rm = TRUE) +
    scale_colour_brewer(palette = "Set1")
  • Point at ?scale_colour_brewer and colorbrewer2.org
  • Gotcha: unnamed labels are matched in data order, not the order you typed – mislabelled legend
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.6, alpha = 0.5) +
    geom_smooth(method = "lm") +
    scale_colour_manual(values = c(Positive = "dodgerblue2",
                                   Negative = "firebrick2"),
                        labels = c(Positive = "ER-positive",
                                   Negative = "ER-negative"))
## `geom_smooth()` using formula = 'y ~ x'
  • Continuous variable -> colour gradient, not discrete palette
ggplot(data = metabric,
       mapping = aes(x = GATA3,
                     y = ESR1,
                     colour = Nottingham_prognostic_index)) +
    geom_point(size = 0.6, alpha = 0.5)
  • Default is black-to-blue; high NPI = worse prognosis, so emphasise it in red
metabric |>
    ggplot(mapping = aes(x = GATA3,
                         y = ESR1,
                         colour = Nottingham_prognostic_index)) +
    geom_point(size = 0.75) +
    scale_colour_gradient(low = "white", high = "red")
  • scale_colour_gradient2() – diverging, two gradients about a midpoint
metabric |>
    ggplot(mapping = aes(x = GATA3,
                         y = ESR1,
                         colour = Nottingham_prognostic_index)) +
    geom_point(size = 0.75) +
    scale_colour_gradient2(low = "dodgerblue1",
                           mid = "grey90",
                           high = "firebrick1",
                           midpoint = 4.5)
