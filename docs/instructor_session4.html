Visualizing data with ggplot2

METABRIC data set

  • Extended METABRIC – clinical columns plus mRNA expression for ESR1, PGR, GATA3, FOXA1
  • Samples without expression data removed, so fewer rows than session 3
  • Spaces in column names replaced with underscores
  • 3-gene_classifier is not a valid R name – starts with a number, contains a hyphen. Needs backticks: metabric$`3-gene_classifier`
  • Valid names: letters, numbers, . and _; must not start with a number
library(tidyverse)
metabric <- read_csv("data/metabric_clinical_and_expression_data.csv")
metabric

Our first ggplot - a scatter plot

  • Same kind of plot as base plot() in earlier sessions, now the ggplot2 way
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1))

Three things specified:

  1. The data – a data frame (or tibble)
  2. The type of plot – a geom
  3. Mapping of variables to visual properties – aesthetics
  • x and y are aesthetics too – counter-intuitive, say it out loud
  • Other aesthetics: size, shape, colour, transparency

Aesthetic mappings

?geom_point

  • In the Aesthetics section, bold = required (x, y); the rest optional

  • Map a variable to colour exactly as for x/y – categorical first

ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, colour = ER_status))
  • Now a continuous variable
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, colour = Nottingham_prognostic_index))

  • Continuous -> colour scale; discrete -> discrete colours

  • Deliberate bad idea: size mapped to a categorical variable

ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, size = ER_status))
## Warning: Using size for a discrete variable is not advised.

  • ggplot warns – size is for continuous variables

  • Setting vs mapping: to fix size for all ~2000 points, set it outside aes()

ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3,
                             y = ESR1,
                             colour = Nottingham_prognostic_index),
               size = 0.5)
  • Converse restriction – shape only takes categorical
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, shape = Survival_time))
Error: A continuous variable can not be mapped to shape
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, shape = `3-gene_classifier`),
               size = 0.9)
## Warning: Removed 204 rows containing missing values or values outside the scale range
## (`geom_point()`).

  • Unclassified samples have NA – ggplot silently drops missing values (warning in console)

  • Colour + shape together – two categorical variables at once

ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3,
                             y = ESR1,
                             colour = PAM50,
                             shape = `3-gene_classifier`),
              size = 0.9)
## Warning: Removed 204 rows containing missing values or values outside the scale range
## (`geom_point()`).
  • alpha (transparency) reveals overplotting – like size, set not mapped
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, colour = `3-gene_classifier`),
               size = 0.75,
               alpha = 0.5)
  • Colours used far more than shape/size/transparency; customization of everything comes later in the course

ggplot2 grammar

  • “gg” = grammar of graphics

ggplot2 grammar of graphics

ggplot(data = <DATA>) + <GEOM_FUNCTION>(mapping = aes(<MAPPINGS>))

ggplot() creates the plot object.

Layers can be added by adding geoms such as geom_point() using the + operator that ggplot2 has overridden for this purpose.

Another plot type - bar chart

  • Full geom list: Packages panel -> ggplot2 -> right-click -> “Show Help” -> scroll to geom_...
  • METABRIC’s integrative clusters – new subtypes defined by the study
  • geom_bar needs only x; it counts rows for you
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster))
  • Try colour – get the class to predict
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster,
                           colour = Integrative_cluster))
  • colour = outline, fill = interior – the point of this pair
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster, fill = Integrative_cluster))
  • Fill with a different variable -> stacked bar plot
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster, fill = ER_status))
  • Same grammar as the scatter plot – only the geom changed
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster, fill = `3-gene_classifier`))
  • Classic mistake – setting a fixed colour inside aes()
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster, fill = "blue"))
  • Inside aes() R invents a variable whose value is the string “blue” for every row, then assigns it a colour from the palette
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster), fill = "blue")

Multiple layers

ggplot(data = <DATA>) +
  <GEOM_FUNCTION>(mapping = aes(<MAPPINGS>))
  • + is overridden by ggplot2 to add layers (geoms) and components (scales, themes)
  • Multiple geoms = multiple layers
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1)) +
    geom_smooth(mapping = aes(x = GATA3, y = ESR1))
## `geom_smooth()` using method = 'gam' and formula = 'y ~ s(x, bs = "cs")'

  • geom_smooth() – fitted trend line; shaded band is the standard error on the fit

  • Gotcha: + must be at the end of the line, not the start of the next

  • Duplicated mappings – lift them into ggplot()

ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1)) +
    geom_point() +
    geom_smooth()
## `geom_smooth()` using method = 'gam' and formula = 'y ~ s(x, bs = "cs")'
  • size/alpha are constants and should apply only to the points – set inside geom_point()
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1)) +
    geom_point(size = 0.5, alpha = 0.5) +
    geom_smooth()
## `geom_smooth()` using method = 'gam' and formula = 'y ~ s(x, bs = "cs")'
  • Aesthetics in ggplot() are global – inherited by every geom
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.5, alpha = 0.5) +
    geom_smooth()
## `geom_smooth()` using method = 'gam' and formula = 'y ~ s(x, bs = "cs")'
  • Unexpected result: two smooth lines, one per ER group – because colour was inherited
ggplot(data = metabric, mapping = aes(x = GATA3, y = ESR1)) +
    geom_point(mapping = aes(colour = ER_status), size = 0.5, alpha = 0.5) +
    geom_smooth()
## `geom_smooth()` using method = 'gam' and formula = 'y ~ s(x, bs = "cs")'
  • inherit.aes = FALSE – opt a layer out of the global mappings entirely
ggplot(data = metabric,
       mapping = aes(x = GATA3, y = ESR1, colour = ER_status)) +
    geom_point(size = 0.5, alpha = 0.5) +
    geom_smooth(mapping = aes(x = GATA3, y = ESR1), inherit.aes = FALSE)
## `geom_smooth()` using method = 'gam' and formula = 'y ~ s(x, bs = "cs")'

Box plots

ggplot(data = metabric, mapping = aes(x = ER_status, y = GATA3)) +
    geom_boxplot()

  • Check ?geom_boxplot for how box, whiskers and outliers are defined

  • Add the raw points as a second layer

ggplot(data = metabric, mapping = aes(x = ER_status, y = GATA3)) +
    geom_boxplot() +
    geom_point()
  • Points stack in a line – ?geom_point points to geom_jitter for a categorical x
ggplot(data = metabric, mapping = aes(x = ER_status, y = GATA3)) +
    geom_boxplot() +
    geom_jitter()
  • Tame it – width controls the spread
ggplot(data = metabric, mapping = aes(x = ER_status, y = GATA3)) +
    geom_boxplot() +
    geom_jitter(width = 0.3, size = 0.5, alpha = 0.25)

  • Showing points matters most with few observations, where a box plot hides small n; here there are too many

  • colour on a box plot splits each box into sub-groups

ggplot(data = metabric,
       mapping = aes(x = ER_status, y = GATA3, colour = HER2_status)) +
    geom_boxplot()

Time series data

  • Line plots for time series – METABRIC has none, so switch data set

COVID-19 data set

  • UK Government COVID-19 press conference data, transport use before/after lockdown
  • Reading from Excel needs care – multiple sheets, header lines and footnotes
  • Date column has no heading, so skip it and supply col_names; col_types gives read_excel a heads-up
library(readxl)
transport_use <- read_excel("data/2020-04-26_COVID-19_Press_Conference_Data.xlsx",
                            sheet = "Transport use",
                            col_names = c("date", "transport_type", "percentage"),
                            col_types = c("date", "text", "numeric"),
                            skip = 4,
                            n_max = 186)
transport_use$percentage <- transport_use$percentage * 100

Dates

typeof(rail_use$date)
## [1] "double"
class(rail_use$date)
## [1] "POSIXct" "POSIXt"
  • Stored as a double – so it works as a continuous x aesthetic
  • Class POSIXct gives it date behaviour (POSIX = cross-platform standard, ct = calendar time)
  • Underlying number = seconds since 1 January 1970
rail_use$date[1]
## [1] "2020-03-16 UTC"
as.double(rail_use$date[1])
## [1] 1584316800

Line plot

  • geom_line – points on successive dates joined by a line; needs x and y
ggplot(data = rail_use) +
    geom_line(mapping = aes(x = date, y = percentage))
  • Back to the full table – colour gives one line per transport mode
ggplot(data = transport_use) +
    geom_line(mapping = aes(x = date, y = percentage, colour = transport_type))
  • linetype – another aesthetic specific to lines
ggplot(data = transport_use) +
    geom_line(mapping = aes(x = date, y = percentage, linetype = transport_type))

Histograms

ggplot(data = metabric) +
    geom_histogram(mapping = aes(x = Age_at_diagnosis))
## `stat_bin()` using `bins = 30`. Pick better value `binwidth`.
  • Default 30 bins triggers a warning – set binwidth
ggplot(data = metabric) +
    geom_histogram(mapping = aes(x = Age_at_diagnosis), binwidth = 5)
  • Or bins for the number of bins instead
ggplot(data = metabric) +
    geom_histogram(mapping = aes(x = Age_at_diagnosis), bins = 20)
  • colour = bar outline, fill = bar interior (as with geom_bar)
ggplot(data = metabric) +
    geom_histogram(mapping = aes(x = Age_at_diagnosis), bins = 20, colour = "darkblue", fill = "grey")

Categorical variables – factors

  • Categorical variables come in as characters (3-gene classifier), numbers (tumour stage) or binary (ER status)
  • ggplot2 already treats character columns as categorical
  • Problem case: a categorical variable read in as a double
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, colour = Tumour_stage))
table(metabric$Tumour_stage)
## 
##   0   1   2   3   4 
##   4 475 800 115   9
  • Only 5 discrete states but ggplot2 used a continuous colour scale – we must tell R it is categorical
  • R’s type for categorical data is a factor
metabric$Tumour_stage <- as.factor(metabric$Tumour_stage)
metabric[, c("Patient_ID", "Tumour_stage")]
## # A tibble: 1,904 × 2
##   Patient_ID Tumour_stage
##   <chr>      <fct>       
## 1 MB-0000    2           
## 2 MB-0002    1           
## # ℹ 1,902 more rows
  • A factor is stored as integers plus metadata mapping each integer to a level
typeof(metabric$Tumour_stage)
## [1] "integer"
class(metabric$Tumour_stage)
## [1] "factor"
levels(metabric$Tumour_stage)
## [1] "0" "1" "2" "3" "4"
ggplot(data = metabric) +
    geom_point(mapping = aes(x = GATA3, y = ESR1, colour = Tumour_stage))
  • Level order controls plot order. Look back at the bar plot – 10 sat between 1 and 2, because it’s a character vector (the ‘4ER-’/‘4ER+’ clusters force this) sorted alphanumerically
metabric$Integrative_cluster <- as.factor(metabric$Integrative_cluster)
levels(metabric$Integrative_cluster)
##  [1] "1"    "10"   "2"    "3"    "4ER-" "4ER+" "5"    "6"    "7"    "8"   
## [11] "9"
  • factor() with the levels argument sets the order explicitly
metabric$Integrative_cluster <- factor(metabric$Integrative_cluster, 
                                       levels = c("1", "2", "3", "4ER-", 
                                                  "4ER+", "5", "6", "7", 
                                                  "8", "9", "10"))
levels(metabric$Integrative_cluster)
##  [1] "1"    "2"    "3"    "4ER-" "4ER+" "5"    "6"    "7"    "8"    "9"   
## [11] "10"
  • forcats (part of the tidyverse) has functions for manipulating levels – fct_relevel moves “10” to the end with far less typing
metabric$Integrative_cluster <- fct_relevel(metabric$Integrative_cluster, 
                                            "10",
                                            after = Inf)
levels(metabric$Integrative_cluster)
##  [1] "1"    "2"    "3"    "4ER-" "4ER+" "5"    "6"    "7"    "8"    "9"   
## [11] "10"
ggplot(data = metabric) +
    geom_bar(mapping = aes(x = Integrative_cluster, fill = Integrative_cluster))
