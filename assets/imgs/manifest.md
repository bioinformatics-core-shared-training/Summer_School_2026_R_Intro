Images for use on site go here, organised as:

- `sessionN/`   - images used only by `sessionN.Rmd` (sessions 1, 6, 7, 8)
- `shared/`     - images used by more than one document
- `logos/`      - institution logos used in the navbar and page footer
- `resources/`  - original/source logo artwork (not referenced by the site)
- `rstudio/`    - RStudio screenshots not currently used
- `installation/` - R/Mac installation screenshots not currently used
- `concepts/`   - concept diagrams and illustrations not currently used
